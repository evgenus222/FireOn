# Управление сайтом FIREON без Cloudflare

Для редактирования сайта используется hosted-версия Pages CMS: https://app.pagescms.org/

## Первый запуск

1. Открой https://app.pagescms.org/ и войди через свой GitHub.
2. Установи официальное приложение Pages CMS для аккаунта GitHub, которому принадлежит репозиторий.
3. Выбери репозиторий `evgenus222/FireOn`.
4. Pages CMS прочитает конфигурацию `.pages.yml` в корне репозитория.
5. Открой нужную страницу или раздел материалов и сохраняй изменения. Pages CMS создаёт коммиты в GitHub, а GitHub Pages обновляет сайт автоматически.

## Что доступно в первой версии

- Главная страница, Wiki, обновления и страница «Как начать играть» - редактор исходного кода HTML.
- Публикации и механики - JSON-файл `data/mechanics.json`.
- Изображения - медиатека в `media/uploads/`.

## Важные особенности

- Cloudflare Worker, KV и отдельное OAuth-приложение не нужны.
- Доступ к репозиторию выдаётся через GitHub App Pages CMS. Устанавливай приложение только для репозитория FIREON и проверяй запрашиваемые разрешения перед подтверждением.
- Это отдельная CMS по адресу Pages CMS, а не прежний визуальный редактор в `admin.html`. HTML-страницы пока редактируются как код, без визуального WYSIWYG-редактора.
- Изменения сохраняются в GitHub. Публикация на GitHub Pages может занять несколько минут.
- Не добавляй токены или пароли в файлы репозитория.
