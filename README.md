# FIREON

Официальный сайт Minecraft-сервера FIREON.

- Сайт: https://evgenus222.github.io/FireOn/
- Адрес сервера: `fireon.gomc.fun`
- Вики: https://evgenus222.github.io/FireOn/wiki.html
- Обновления: https://evgenus222.github.io/FireOn/updates.html
- Как начать: https://evgenus222.github.io/FireOn/join.html
- Админ-панель: https://evgenus222.github.io/FireOn/admin.html

## Структура

- `index.html` - главная страница проекта.
- `wiki.html` - происхождения, правила и механики.
- `updates.html` - лента публикаций из `data/mechanics.json`.
- `join.html` - инструкция по подключению.
- `admin.html` - FIREON Studio.
